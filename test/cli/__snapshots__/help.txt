Usage: diffle [options] [command] [revs...]

Review a git diff in the browser and export line comments as an agent prompt.

Arguments:
  revs                       git-diff style revisions: <rev> | <a>..<b> |
                             <a>...<b> | <a> <b>

Options:
  -v, --version              print the version and exit
  -C <path>                  run as if started in <path> (any directory inside a
                             git worktree)
  -p, --port <port>          port to listen on (default: 4966, or the next free
                             one; 0 = random)
  -H, --host <host>          address to bind; use 0.0.0.0 to expose on the
                             network (default: "127.0.0.1")
  --allowed-origin <origin>  trusted public HTTP(S) origin behind a reverse
                             proxy (without a path)
  --no-open                  do not open a browser
  --keep-alive               keep the server running after all browser tabs
                             close
  --no-watch                 do not watch for changes
  --auto-viewed <glob>       mark matching files viewed for this session
                             (repeatable) (default: none)
  -U, --context <n>          context lines around changes for this session
                             (default: config, 5)
  --lsp <language=command>   language server command for one language, started
                             for this run (repeatable); by default the diff's
                             languages are served by whatever is on PATH
                             (default: the diff's languages, resolved on PATH)
  --no-lsp                   do not start any language server
  --timing                   print startup phase timings to stderr
  --dev                      serve the client through Vite (development)
  -h, --help                 display help for command

Commands:
  config                     show or edit the user config (same settings as the
                             UI dialog)
  lsp                        show the language server each language would get,
                             and what is missing from PATH
  completion [options]       print a shell completion script for bash, zsh, or
                             fish

Shorthands (in place of <revs>):
  working                  same as HEAD..worktree: uncommitted changes, staged and untracked included
  pr [number|url]          a GitHub pull request: its base...head, fetched if needed
                           (without an argument: the pull request for this branch)

Revisions follow git diff, except that a lone one compares from the merge base:
  diffle main              same as main...HEAD: what this branch added since it left main
  diffle HEAD~3            the last three commits
  diffle main..feat        main vs feat
  diffle main...feat       what feat added since it left main
  diffle main..worktree    main vs the uncommitted tree ("worktree" works on either side)

Without revisions, diffle compares HEAD..worktree.

Status goes to stderr, so stdout carries only the review: unless --keep-alive is set,
closing the last auto-opened browser tab stops diffle and prints the open comments as a prompt for an agent.
Ctrl+C always stops it.
